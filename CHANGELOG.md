# Changelog

## 1.0.1 — 2026-10-29

### Добавлено

- Экспорт текущей кривой и любого factory/user-пресета в **AutoEq / Equalizer APO** (`.txt`).
- Ручной ввод частоты, gain и Q в инспекторе: точные значения, поддержка `440`, `1.2k`, `1,2 kHz`, `+3.5`, `−2`.
- `make_dmg.sh` для сборки drag-to-Applications установщика.

### Исправлено / улучшено

- Поля значений клампятся в допустимый диапазон, невалидный ввод откатывается.
- Экспорт сохраняет `ON/OFF`, типы фильтров и POSIX-десятичную точку.
- About-панель берёт версию из `Info.plist`.
- Обновлены README, DMG/ZIP-документация и чистый Git-репозиторий.

## 1.0.0

- Первый релиз: системный параметрический эквалайзер, process tap, spectrum, пресеты, AutoEq-импорт, Dock/menu bar.
